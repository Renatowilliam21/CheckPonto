# Requisitos Funcionais

| ID | Requisito |
| --- | --- |
| **RF01** | Permitir autenticação por login e senha. |
| **RF02** | Permitir ao coordenador cadastrar, consultar, alterar e desativar participantes. |
| **RF03** | Permitir atribuir perfis de acesso aos usuários. |
| **RF04** | Permitir ao participante consultar suas informações individuais. |
| **RF05** | Impedir acesso não autorizado aos dados individuais de outros participantes. |
| **RF06** | Permitir cadastrar e gerenciar laboratórios. |
| **RF07** | Permitir associar coordenadores aos laboratórios. |
| **RF08** | Permitir cadastrar projetos. |
| **RF09** | Permitir associar participantes aos projetos. |
| **RF10** | Permitir cadastrar tipos de vínculo. |
| **RF11** | Permitir associar vínculos aos participantes. |
| **RF12** | Permitir cadastrar cartões RFID. |
| **RF13** | Permitir associar cartão RFID a participante. |
| **RF14** | Permitir ativar ou bloquear cartão RFID. |
| **RF15** | Permitir cadastrar terminais RFID. |
| **RF16** | Permitir ao terminal identificar o UID do cartão. |
| **RF17** | Permitir ao terminal transmitir eventos para a API. |
| **RF18** | Fornecer confirmação visual ou sonora no terminal. |
| **RF19** | Armazenar temporariamente eventos quando o terminal estiver sem comunicação. |
| **RF20** | Sincronizar eventos pendentes quando a comunicação for restabelecida. |
| **RF21** | Permitir ao coordenador cadastrar programação semanal individual. |
| **RF22** | Permitir definir dias, horários e carga prevista. |
| **RF23** | Calcular carga horária semanal prevista. |
| **RF24** | Permitir programações diferentes conforme o tipo de vínculo. |
| **RF25** | Preservar histórico das programações anteriores. |
| **RF26** | Registrar data, hora, cartão, participante e terminal de cada batida. |
| **RF27** | Interpretar automaticamente a sequência das batidas. |
| **RF28** | Identificar jornadas com e sem intervalo de almoço. |
| **RF29** | Calcular automaticamente a carga horária diária. |
| **RF30** | Descontar o intervalo de almoço da carga realizada. |
| **RF31** | Calcular carga horária semanal realizada. |
| **RF32** | Comparar carga prevista e realizada. |
| **RF33** | Identificar registros incompletos ou inconsistentes. |
| **RF34** | Permitir ao participante solicitar correção de ponto. |
| **RF35** | Exigir justificativa para solicitação de correção. |
| **RF36** | Permitir ao coordenador aprovar ou rejeitar solicitações de correção. |
| **RF37** | Preservar registro original e histórico das correções. |
| **RF38** | Registrar faltas justificadas e não justificadas. |
| **RF39** | Permitir ao participante apresentar justificativa de ausência. |
| **RF40** | Permitir ao coordenador analisar justificativas. |
| **RF41** | Permitir cadastrar feriados. |
| **RF42** | Permitir cadastrar recessos. |
| **RF43** | Permitir cadastrar afastamentos individuais. |
| **RF44** | Considerar calendário, afastamentos e justificativas na situação semanal. |
| **RF45** | Permitir ao participante registrar atividades desenvolvidas diariamente. |
| **RF46** | Relacionar atividade a participante e data. |
| **RF47** | Apresentar automaticamente a carga registrada junto à atividade diária. |
| **RF48** | Impedir alteração manual da carga horária proveniente do ponto. |
| **RF49** | Permitir editar atividade enquanto o período estiver aberto. |
| **RF50** | Permitir registrar resumo semanal. |
| **RF51** | Gerar consolidação semanal automaticamente. |
| **RF52** | Apresentar carga prevista, realizada e saldo. |
| **RF53** | Apresentar registros diários e atividades na consolidação semanal. |
| **RF54** | Permitir ao participante enviar relatório semanal. |
| **RF55** | Permitir ao coordenador aprovar relatório semanal. |
| **RF56** | Permitir ao coordenador devolver relatório com observação. |
| **RF57** | Permitir corrigir e reenviar relatório devolvido. |
| **RF58** | Registrar data e responsável pela aprovação. |
| **RF59** | Disponibilizar dashboard individual do participante. |
| **RF60** | Apresentar progresso da carga semanal. |
| **RF61** | Disponibilizar dashboard administrativo do coordenador. |
| **RF62** | Exibir participantes atualmente presentes no laboratório. |
| **RF63** | Exibir carga prevista e realizada por participante. |
| **RF64** | Identificar participantes com carga horária pendente. |
| **RF65** | Identificar atividades diárias ainda não preenchidas. |
| **RF66** | Exibir relatórios semanais pendentes de análise. |
| **RF67** | Exibir ocorrências e solicitações de correção pendentes. |
| **RF68** | Permitir consultar registros por participante e período. |
| **RF69** | Gerar relatório semanal individual. |
| **RF70** | Gerar relatório mensal individual. |
| **RF71** | Gerar relatório para período personalizado. |
| **RF72** | Apresentar carga prevista e realizada nos relatórios. |
| **RF73** | Apresentar atividades desenvolvidas nos relatórios. |
| **RF74** | Apresentar resumos semanais nos relatórios. |
| **RF75** | Apresentar ocorrências relevantes nos relatórios. |
| **RF76** | Permitir exportar relatórios em PDF. |
