# Requisitos Não Funcionais

| ID | Requisito |
| --- | --- |
| **RNF01** | A aplicação web deverá possuir interface responsiva. |
| **RNF02** | A comunicação entre terminal e servidor deverá utilizar API HTTP/HTTPS. |
| **RNF03** | Senhas não poderão ser armazenadas em texto puro. |
| **RNF04** | A API deverá exigir autenticação dos terminais RFID. |
| **RNF05** | O sistema deverá implementar controle de acesso baseado em perfil. |
| **RNF06** | Operações administrativas relevantes deverão possuir auditoria. |
| **RNF07** | O terminal deverá armazenar temporariamente eventos durante indisponibilidade da rede. |
| **RNF08** | A sincronização deverá ser idempotente e não produzir registros duplicados. |
| **RNF09** | Data e hora deverão possuir origem controlada e consistente. |
| **RNF10** | O sistema deverá preservar integridade e rastreabilidade dos registros de frequência. |
| **RNF11** | O sistema deverá adotar medidas adequadas de proteção de dados pessoais. |
| **RNF12** | O código-fonte deverá ser versionado utilizando Git. |
